1. Project Title
A Multi-Platform Smart Transport Management System (STA Ride)
2. INTRODUCTION / BACKGROUND
The transportation industry is undergoing rapid digital transformation due to advancements in mobile computing, internet connectivity, and real-time communication technologies. In modern urban environments, people increasingly rely on digital platforms to access transportation services quickly, efficiently, and safely. Ride-hailing systems such as Bolt and Uber have significantly changed how passengers interact with drivers by offering on-demand transport services through mobile applications.
Despite these advancements, many developing regions, including Tanzania, still face several transportation challenges such as delayed driver-passenger matching, poor communication, inaccurate GPS positioning, lack of centralized monitoring systems, and limited safety features for vulnerable users.
To address these challenges, this project proposes the development of STA Ride, a Multi-Platform Smart Transport Management System designed to provide a modern, secure, and scalable transport solution. The system integrates three major components:
• Rider Application
• Driver Application
• Administrator Dashboard
The system is expected to improve transport accessibility, operational efficiency, safety, and communication between riders, drivers, and transport administrators.
3. PROBLEM STATEMENT
Although existing ride-hailing systems have improved transportation accessibility, several operational and technological challenges still exist.
Existing Problems
3.1 Operational Inefficiency
Many transport systems experience delays in matching riders with nearby drivers, leading to long waiting times and reduced customer satisfaction.
3.2 Lack of Centralized Oversight
Administrators often lack effective tools to monitor driver activities, ride history, earnings, and safety metrics in real time.
3.3 Communication Gaps
Poor synchronization between riders and drivers may cause missed requests, delayed notifications, and inefficient coordination during pickups.
3.4 Development and Maintenance Cost
Developing separate applications for riders, drivers, and administrators increases development complexity and maintenance costs.
Additional Problem: GPS Pickup Inaccuracy
One of the major limitations in existing ride-hailing systems is inaccurate GPS positioning during ride requests. GPS signals may fluctuate because of:
• Poor internet connectivity
• Tall buildings
• Environmental interference
• Device hardware limitations
As a result:
• Drivers fail to locate passengers accurately
• Riders experience long waiting times
• Pickup locations become incorrect
• Communication delays increase frustration
Most current systems depend entirely on standard GPS tracking without intelligent alternatives when GPS becomes unstable.
Proposed Innovation
To solve this challenge, the proposed STA Ride system introduces an:
AI-Assisted Visual Pickup Positioning System
The feature allows riders to:
• Capture photos of their surroundings
• Extract GPS coordinates from image EXIF metadata
• Use AI-based landmark recognition when coordinates are unavailable
• Automatically correct pickup pin locations
• Share visual pickup references with drivers
This innovation improves:
• Pickup accuracy
• Driver navigation
• Passenger identification
• Communication efficiency
• Overall ride experience

7. SYSTEM ARCHITECTURE
The STA Ride system follows a Modular Client-Server Architecture consisting of:
7.1 Presentation Layer
Three application modules generated from one Flutter codebase using Product Flavors:
• Rider App
• Driver App
• Admin App
7.2 Application Layer
A Node.js server responsible for:
• Business logic
• Authentication
• Ride matching
• Real-time communication
7.3 Data Layer
SQLite database for:
• User data
• Ride records
• Driver information
• System configurations
7.4 Communication Layer
Hybrid communication using:
• REST APIs for data transactions
• Socket.IO WebSockets for real-time synchronization
